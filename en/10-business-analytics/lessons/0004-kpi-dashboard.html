Business Intelligence and Dashboards

The meeting-room screen crams in forty numbers, and when the meeting breaks, nobody remembers a single decision. A Dashboard is not a “chart storage box” — it is a decision cockpit: one North Star sets the direction, one metric tree sets the structure, and one set of linked interactions and alerts handles the exceptions. This lesson assembles the process, the statistics, and the causal guardrails of the first three lessons into an interactive mini dashboard.

1The North Star Metric: The One and Only Star

Concept Card · North Star Metric

The single metric that best captures “the value users get from the product”: when user value grows, it grows; and when it keeps growing, long-term business results are rarely bad. Subscription businesses commonly use “monthly active subscriptions” or “total time spent”, while e-commerce commonly uses a gross-merchandise-value measure (illustrative). Three lines qualify it: it reflects user value (not the revenue the company extracts), it is decomposable (splittable into sub-metrics that teams can move), and it is influenceable (action can push it). Classic counter-example: “cumulative registered users” — it only ever rises, reflecting no value and guiding no action.

2Metric Trees and Dimensional Drill-Down

Revenue = Traffic × Conversion Rate × Average Order Value × Repeat Purchases

A Metric Tree breaks a big metric into small, attributable, actionable ones: when total revenue stalls, check first whether traffic has plateaued, conversion is slipping, or average order value is weakening. Pinpointing “which cell” takes Drill-Down: slicing layer by layer along dimensions (an old friend from Lesson 1) such as region, channel, and category, narrowing “overall softness” down to “a problem in one channel at one stage”. Decompose to locate where first, then apply Lesson 3’s causal guardrails to ask why.

3Three Principles of Dashboards

  1. One screen, one decision. Every screen answers one operating question; decorative charts with no decision attached get deleted. More metrics does not mean more professional — it means fewer readers.
  2. Compare period over period. Absolute numbers say almost nothing: “¥9,800,000 in sales this month” — good or bad, nobody knows. Compare month-over-month (MoM, against the prior period) to read momentum and year-over-year (YoY, against the same month last year) to strip out seasonality — if ice cream sells well in August, hold the good-news memo.
  3. Alerting. Set thresholds and anomaly rules on key metrics so the system watches them 24/7 and people handle only the exceptions. Watching screens is not work; handling exceptions is.

Case · Spotify and Netflix: Choosing “the Value Users Receive” as the North Star

What should a subscription content business pick as its North Star? In public interviews and product discussions, Spotify has long gauged user value with listening-time metrics — the more users listen, the better retention and paid conversion (per public sources, illustrative). Netflix treats total watch time as the core thermometer of its membership business and discloses related figures regularly in its shareholder letters (public figures, illustrative). The common thread: the North Star measures the value users receive (listening and watching), not the revenue the company collects (subscription fees), and the metric tree below the North Star branches into content, recommendations, and acquisition channels. The counter-example is “new downloads” as a North Star — downloads are not listening, let alone value: inflated downloads paired with dismal retention are exactly the makeup job that paid traffic acquisition does best.

The lesson: set the North Star first (user value), then split the metric tree (growth levers), and keep only the decision-critical tiles on the dashboard. Metrics are not better when more numerous — they are better when they lead to action.

Key Terms

North Star Metric
The one metric that best represents the value users receive — decomposable and influenceable — aligning everyone’s direction.
Metric Tree
A structure that decomposes a core metric layer by layer into attributable, actionable sub-metrics.
Drill-Down
Slicing a metric layer by layer along dimensions such as region, channel, and category to locate the problem cell.
Year-over-Year (YoY)
Comparison against the same period last year, used to strip out seasonality and read the long-term trend.
Month-over-Month (MoM)
Comparison against the prior period, used to watch short-term momentum and anomalies.
Retention Rate
The share of a period’s users still active in later periods; measures real value and channel quality.
Alerting
Thresholds and anomaly rules set on key metrics, with the system alerting automatically so people handle only exceptions.
Key Takeaways

A dashboard is a cockpit, not a poster: one North Star, one metric tree, three principles — one screen one decision, MoM and YoY comparisons, alerting; drill down to locate which cell went wrong, then apply causal thinking to ask why.
